# Run-level aggregate results

`summary.csv` contains one post-warm-up mean per run and reports mean plus 95% confidence interval across the 30 held-out test seeds. `paired_comparison.csv` matches baseline and ML outputs by base seed and reports the paired effect, its 95% confidence interval, Cohen's dz, and paired t statistic.

The rows must not be used as a claim about vehicular-network performance because their source is the controlled development model. They are retained as an auditable validation of the multi-seed methodology.
